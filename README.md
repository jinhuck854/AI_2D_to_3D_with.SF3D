# 1. Introduction
### :bulb: 주제 : 실감응용인공지능 개인 프로젝트, `챗봇을 활용한 2D to 3D AI 모델링`

### :triangular_flag_on_post: 목표
1. 원하는 2D 이미지 생성 후 3D 모델링 제작
2. 좋은 퀄리티의 결과물
3. 간단한 웹 서비스 형태로 제공

### :heart: 주요 기능
1. Colab을 사용하여 어디서든 사용 가능함.
2. 챗봇을 통해 2D 이미지를 생성함.
3. SF3D를 통해 3D 모델링을 생성함.
4. 2D 및 3D 모델링 다운로드 가능함.
5. 웹페이지 UI를 통해 간단한 기능 제공함.
